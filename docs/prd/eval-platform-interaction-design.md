# 评测工作台交互设计 v0.8

更新日期：2026-08-31。基于现有双入口工作台的交互优化，使用 UI Skills 的 Clarify 规范和 Impeccable 的 Operate / Layout 规范；保留浅色绿色视觉系统。本轮交付是可点击原型与需求补充，不实现后端发布、环境构建或真实模型调用。

[打开交互原型](eval-platform-closed-loop.html)。首页预置一组明确标为合成数据的结果，便于直接查看判据和证据；真实产品没有运行记录时显示空状态。

## 页面与阅读顺序

| 入口       | 默认阅读顺序                                             | 主要行动                                 |
| ---------- | -------------------------------------------------------- | ---------------------------------------- |
| 离线评测   | 数据集与默认配置 → 结果分布 → 逐条用例 → 判据 → 相关证据 | 启动、取消、筛选、定位证据、记录异议     |
| Trace 审核 | 去重队列 → 来源事实 → 独立任务包节点 → 检查报告          | 保存草稿、补材料、检查、发布、审核下一条 |

两个入口继续共用后端。发布检查与评分异议留在详情内；环境制作从用例详情进入独立子页面，完成后回填原用例，不新增顶层管理入口。版本对比、自动根因与自动优化仍不属于本轮原型。

## 离线评测

离线评测下提供「新建评测 / 执行历史」两个子入口，不增加顶层导航。[直接打开执行历史](eval-platform-closed-loop.html#history)。历史页默认跨评测集展示，支持集合、状态、北京时间创建日期范围、运行编号精确查询，每页 5 条；查询提交后生效，重置恢复全部记录。

列表显示运行编号与创建时间、集合冻结版本、Agent / 模型、执行状态、分类结果、已处理数量及耗时。点击「查看详情」进入独立历史详情，先看冻结配置与时间，再沿用结果、判据和证据下钻；「返回执行历史」保留已提交筛选、页码和滚动位置。查询无匹配与查询错误区别展示，详情内不混入当前新建评测配置。

预置 7 条跨集合合成记录，覆盖完成、取消、出错与中断；新启动的模拟任务立即追加，排队、执行和取消都保留该条记录。历史页的「原型边界与异常演示」可模拟查询失败与重试，不创建新运行。筛选和分页仅为本页模拟，不代表后端持久化；刷新恢复预置数据。

页面上方保留集合选择和启动按钮，回显数据集版本、默认 Agent、默认评分器、环境隔离方式。用例列表和 Agent 接入能力放在展开区；正式版从后端目录读取，不允许浏览器传任意路径或命令。能力摘要明确区分结果验证、工具记录和请求详情。

首次使用显示空状态；预置示例、模拟运行、真实运行必须使用不同标识。开始前检查配置、权限和预算；当前费用复选框只演示真实调用的确认边界，点击不会付费。后台排队与正在执行时禁止重复启动，取消保留部分结果。

结果分布用一条分段条表达“通过 / 不通过 / 未判定 / 未完成”，下方图例就是筛选按钮，带文字、数量和选中状态。比例分母是该运行冻结的用例总数，不将未判定从分母中悄悄移除，不将样本分布解释为线上质量。

桌面采用左侧用例列表、右侧详情；优先展示不通过，再展示未判定。详情首先给出结论和原因，随后列出逐项必选判据、验证方式和“定位证据”入口。

五个证据节点按记录顺序排列：任务输入、工具执行、最终回答、独立核验、逐项评分。点击节点显示对应摘要，原始字段再次展开。点击某条判据的“定位证据”选中其对应节点。真实实现应保留模型调用、工具调用及子 Agent 的细粒度事件；这五个节点只是合成示例的分组视图，不构造虚假的线性调用历史，也不表示已证明根因。

“对评分有异议”在原位展开理由输入，保存后关联精确评分记录并与机器结果并列。不得修改机器汇总。原型中的 S1 与 trial 标识仅在本次合成运行内有效，正式实现需使用真实的 scoreAttemptId / executionId。

## Trace 到任务包

队列继续按分类和审核状态筛选，重复记录只折叠展示。开始整理后收起来源长文本，保留可展开的任务、回答、工具与原始记录。原始 Trace 与改写稿分开保存；缺少内容授权时不能整理为可靠用例。

任务包使用四个可点击节点，序号表达处理顺序，当前节点与材料状态分别显示：

| 节点 | 默认字段                         | 说明与异常处理                                                   |
| ---- | -------------------------------- | ---------------------------------------------------------------- |
| 任务 | 标题、独立任务输入               | 不预填旧错误回答为标准答案；切换节点保留输入                     |
| 环境 | 已发布环境、制作环境或文本上下文 | 没有合适环境可进入制作子页；由任务作者准备，不能填用户机器路径   |
| 验收 | 一行一项的必选条件               | 验证方式由模板提供；新领域判据需要校准，不能仅按“已填写”视为有效 |
| 发布 | 目标集、用途与隐私确认、检查报告 | 所有材料通过检查后才发布；修改材料使旧检查失效                   |

“材料已填”仅表示字段具备，不表示隐私审核、环境复现或验证器自检通过。没有合适模板时，可保存为“环境待准备”或点击“制作环境”；模板详情以键值表展示环境配方、Agent 可见材料、平台保管材料和模板自检证据。

检查报告逐项展示状态、原因与“去补充”。原型只运行本地字段检查，并明确注明不会扫描隐私或执行容器。正式发布必须由服务端校验授权、权限、隐私、环境摘要、可重复准备、错误制品与正确制品自检结果；Agent 必须看不到参考解、隐藏测试实现和评分提示词。

发布后显示新的集合版本，可跳转该集合或审核下一条。重复点击不产生第二个示例用例。正式服务需以发布操作幂等键、修订号与原子事务保证一致性，不能靠前端按钮实现。当前演示为一个来源组发布一个用例，不限制将来一组多用例的领域能力。

## 环境制作子页

[直接打开制作环境演示](eval-platform-closed-loop.html#environment)。使用 UI Skills / Impeccable 的渐进披露和状态反馈规则，将字段组织为四步：配置环境 → 准备项目 → 验证与参考解 → 构建与自检。文件目录表达材料归属，六个检查节点表达执行状态；不要求作者拖拽搭建流程图。

主区编辑当前步骤，侧栏持续显示 instruction / environment / tests / solution / 配置的归属。提供 Node 合成缺陷项目的可编辑文件，不读取本机目录；程序验证和参考解保留在平台侧。任务输入沿用来源用例，返回修改后旧自检失效。

构建与自检展示材料、构建、启动重置、参考解、空跑、重复复现六个节点。失败停止后续节点，可点击查看日志、返回对应材料；取消保留部分记录。成功后还需人工复核才能保存环境版本并回填。保存环境不等于用例发布；修改已使用的环境生成新版本，旧引用不变。完整社区依据、生产边界和数据契约见 [环境制作设计](eval-environment-authoring.md)。

## 图表与字段的边界

| 信息                 | 呈现方式            | 交互                                     |
| -------------------- | ------------------- | ---------------------------------------- |
| 任务包准备进度       | 四步节点            | 直接跳到待补材料，保留草稿               |
| 环境材料与自检       | 文件分区 + 六步节点 | 编辑材料、查看日志、定位失败、修改重检   |
| 来源与产物关系       | 简短关系链          | 说明 Trace、任务包、版本、新证据互相独立 |
| 本次结果构成         | 分段条 + 数量图例   | 点击图例筛选，颜色不是唯一提示           |
| 判据与证据关联       | 判据行 + 证据节点   | 定位到对应工具输出或回答                 |
| 环境、能力、版本字段 | 标签与键值表        | 常用摘要可见，技术详情展开               |
| 模型请求和工具原文   | 按需展开的原始字段  | 保留缺失标记，按不可信文本转义           |

不增加雷达图、无法解释的总分、无数据的趋势图或可拖拽的流程编辑器。节点用于导航和解释，不让审核者搭建执行 DAG。

## 响应式与可访问性

宽屏左右联动；窄屏改为上方可滚动列表、下方详情，避免横向拖动画布。证据节点允许换行，任务包节点保持四步短标签。只有用例明细表允许区域内横向滚动，正文不得横向溢出。

使用原生按钮、表单、details 和列表。图表有等价文字，节点声明选中状态；切换后定位对应标题，输入错误关联字段并通过 live region 宣读。草稿输入和异议理由在页内切换保留；刷新清空的限制始终可见。页面没有自动播放或装饰性动画。

## 交互验收

1. 首页可直接查看合成失败样例，点击判据与节点能对应同一条执行证据。
2. 筛选未判定时只显示证据不足任务；筛选零条状态时给出恢复提示。
3. 保存评分异议后机器结果、数量与历史评分不变。
4. 编辑任务 → 跳到发布 → 检查材料缺失 → 返回环境补齐 → 确认授权 → 重新检查 → 模拟发布，全过程草稿不丢。
5. 检查后修改任何材料，发布按钮失效，重新检查才可发布。
6. 模拟发布生成新版本并能进入离线页；人工任务模拟运行仍显示未判定，不挪用来源输出。
7. 取消运行保留已返回结果，未执行项单列；历史运行保持原数据集版本。
8. 检查桌面与手机布局、按钮键盘可达、原始文本转义和控制台错误。
